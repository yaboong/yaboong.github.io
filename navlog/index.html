User Guide

For the best experience, please use the desktop Chrome browser.
  • Input Order: Enter data in the order shown. Click the in Header to see how the values relate. (colors match the tooltip colors below)
    • Pink = POH
    • Blue = Weather
    • Purple = Compute
  • Tooltips: hover any of these icons (tap on mobile) for a detailed explanation of exactly where to pull that value from.
    • P check the POH (written against the PA-28-161)
    • W check the Weather
    • C Compute (CX-3/E6B)
  • Header's SAMPLE icon: Load sample data, (click to clear everything)
  • Data Storage: saved to this browser only, not a permanent or shared store — use export / import to save or load a plan as a file.
  • Input Guide: every section has a GUIDE button next to its header — click it for a detailed guide on how to use that section.

PPOH 5-19 Climb Performance

*required: Cruise OAT/PA On-course Checkpoint

  • 3–5 NM from Departure
  • Climb FPM * ETE → ALT

PPOH 5-20 Fuel, Time and Distance to Climb

*required: Cruise OAT/PA, Departure OAT/PA ToC (Top of Climb)

  • Climb TAS: 79 kts

CDistance: (Alt to Lose / 1000) × 3 NM ToD (Top of Descent)

  • Descend TAS: 90 kts
  • 3° Descent: GS × 5 fpm → 1,000 ft per 3 NM
  • Distance: (Alt to Lose / 1000) × 3 NM
  • Alt to lose: Cruise ALT − TPA

BoD (Bottom of Descent)

  • Target altitude: TPA
  • 3–4 NM from Destination
